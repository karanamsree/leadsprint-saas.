Production SaaS Architecture & Technology Stack

Complete blueprint to deploy this multi-tenant lead generation and WhatsApp outreach SaaS platform.

1 Backend & Database Stack

  • FastAPI (Python) or Node.js (NestJS): High-speed asynchronous REST API server.
  • PostgreSQL + PostGIS: Spatial database for state, district, and mandal polygon boundaries.
  • Redis + Celery / BullMQ: Asynchronous task queue for long-running scraping jobs and message queuing.
  • JWT + WhatsApp/SMS OTP (Twilio / MSG91): Verifies phone numbers and locks each client tenant to their unique device.

2 Scraping Pipeline (Mandal-Wise)

  • Playwright / Puppeteer Cluster: Headless browser workers running on residential proxy pools.
  • Sources: Google Places API, Local B2B Directories (IndiaMART, Justdial, TradeIndia), MSME Udyam Registries.
  • AI Entity Extraction: LLM extracts contact person names, WhatsApp valid numbers, and categorizes intent.
  • Anti-Bot & Rate Limits: Automatic CAPTCHA solving with 2Captcha/BrightData rotation.

3 WhatsApp Cloud API & Delivery

  • Official Meta WhatsApp Business Cloud API: Prevents phone number banning using registered pre-approved HSM templates.
  • Fallback Click-to-Chat (`wa.me`): Allows instant 1-click personal WhatsApp web dispatch without API fee.
  • Webhook Listener: Receives real-time delivery (`sent`, `delivered`, `read`) and prospect replies.
  • DLT / TRAI Compliance: Follows Indian telecom regulations for commercial messaging.

4 Multi-Tenant Client Security

  • Tenant Isolation: Database row-level security (RLS) guarantees client data is never accessible to competitors.
  • Device Binding & OTP Lock: Locks account session to client's registered mobile number.
  • Role-Based Access: Sub-accounts for loan agents with restricted export permissions.
  • Audit Logs: Tracks every scrape request and outreach campaign.
